## 03장 AWS를 잘 쓰려면 알아야 하는 기본 서비스

### 3.1 AWS에서 동작하는 웹 서비스 구조와 원리 파악하기

안전하고 확장성 있는 웹 서비스는 기본적으로 클라우드 기반으로 구축되며, **AWS IAM**(보안/권한), **Amazon EC2**(컴퓨팅), **Amazon RDS**(데이터베이스), **Amazon S3**(스토리지)와 같은 핵심 서비스를 결합하여 구성하고 운영함.

### 3.2 권한 관리 서비스, AWS IAM 파악하기

#### 3.2.1 AWS IAM이란?

AWS 계정 내에서 사용자와 그룹 또는 리소스에 대한 접근 권한을 중앙 집중적으로 통제하고 관리하는 핵심 보안 서비스임.

#### 3.2.2 AWS IAM 살펴보기

- **루트 사용자 vs IAM 사용자:** 루트 사용자는 시스템의 모든 작업을 수행할 수 있는 절대적인 관리자 권한을 가짐. 따라서 보안상 루트 사용자 직접 사용은 피하고, 최소한의 필요한 권한만 부여된 IAM 사용자를 생성하여 실무에 투입하는 것을 권장함.
- **주요 구성 요소:** 같은 권한이 필요한 사용자를 묶는 **그룹(Group)**, 구체적인 권한을 정의하는 **정책(Policy)**, 그리고 리소스나 서비스에 일시적으로 권한을 부여할 때 사용하는 **역할(Role)** 이 있음.

### 3.3 AWS IAM 생성하기

#### 3.3.1 클라우드포메이션으로 AWS 사용자 생성하기

IaC(Infrastructure as Code) 도구인 클라우드포메이션의 `.yml` 템플릿을 활용하여 리소스를 일관성 있게 프로비저닝할 수 있음. 일반적으로 `VPC.yml → IAM.yml → Security_Group.yml → EC2.yml` 순서로 스택을 생성함.

#### 3.3.2 UI로 불러와 AWS 사용자 리소스 생성하기

AWS 관리 콘솔 화면에서 사용자를 직접 추가하고 관리형 정책을 손쉽게 연결할 수 있음.

#### 3.3.3 AWS CLI 환경 구성하기

터미널에서 AWS 리소스를 제어하기 위해 로컬 PC에 CLI 도구를 설치하고, 발급받은 액세스 키를 `.aws` 디렉토리 내 자격 증명 파일에 구성함.

#### 3.3.4 AWS MFA 설정하기

계정 탈취를 막기 위해 MFA(다중 인증) 설정은 필수임.

- 가상 MFA 디바이스를 생성하고 시리얼 넘버를 확인함.
- Google Authenticator와 같은 앱으로 QR 코드를 스캔한 후, 약 30초마다 갱신되는 6자리 일회용 코드 2개를 연속으로 입력하여 설정을 완료함.
